## 2. 实现（三层）

```
YAML _parse_yaml          超限 skip + WARNING（对齐 RESERVED kind）
register_system_prompt…   超限 raise（既有 fail-closed）
render_content()          出口 enforce_max_chars 截断 + WARNING
  ├─ none                 静态 content
  ├─ mustache             渲染后 cap（防 {{var}} 膨胀）
  └─ plugin_callable      调 _plugin_callable → 按 _plugin_max_chars cap
_resolve_section          统一走 render_content()
```

上限优先级：插件 `_plugin_max_chars` > YAML/metadata `max_chars` > 默认 **8000**。

超限处置：**截断 + WARNING**（可见、不整段丢弃、不静默）；加载面则 **skip + WARNING**
（一个坏文件不拖垮整包）。在库 37 YAML 最大 `kanban` 4056 ≪ 8000，gold 零影响。

顺手接入 `plugin_callable` 渲染引擎（S2.2 注释写「才接入」，此前 Callable 注入恒空串）。
