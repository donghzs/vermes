# ScholarForge P2 风格学习 实施报告
**时间**: 2026-07-08 20:10
**目标**: 补齐 P2 核心功能——从用户示例论文学出个人写作风格，写新章节时自动仿写

---

## 一、产品定位

**不是"降AI率"（事后救火），而是"仿写你的声音"（事前预防）。**

头部框架（千笔AI等）的真正护城河不是检测+降重，而是**学习用户声音**。
用户习惯自己搜文献、大量阅读、再动笔——风格素材就在工作流里。

## 三、风格指纹维度

| 维度 | 提取方式 | 示例输出 |
|------|---------|---------|
| 领域术语 | TF 高频（去停用词+去碎片） | 户外建构, 建构游戏 |
| 术语密度 | 术语/总词数 | 0.96 |
| 句长 | 平均字 + CV（节奏） | 19字, 均匀 |
| 句式偏好 | 长/短/混合 | mixed |
| 段落 | 平均段长 + 主题句位置 | 63字, 段首 |
| 过渡短语 | 从用户文本学（非硬编码） | 首先, 其次, 最后, 基于 |
| 引用格式 | numbered / author_year | [n] |
| 章节顺序 | H2+ 标题序列 | 引言→方法→结果→讨论 |

---

## 四、工作流

```
用户上传 2-5 篇示例论文
        ↓
extract_style() × N 篇
        ↓
merge_profiles() 聚合（均值/高频）
        ↓
save_style_profile(user_id) → SQLite
        ↓
后续 scholarforge_write 自动加载
        ↓
generate_style_prompt() 注入 prompt 顶部
        ↓
LLM 生成时匹配用户风格
```
