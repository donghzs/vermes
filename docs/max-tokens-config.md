# max_tokens 配置说明

## 什么是 max_tokens？

`max_tokens` 控制模型单次回复的最大 token 数量。

## 默认行为

**不设置 max_tokens**（推荐）：
- 让模型自己决定输出长度
- 不会截断长回复
- 最灵活，适合大多数场景

## 何时需要设置？

| 场景 | 建议 |
|------|------|
| 日常对话 | 不设置（让模型自己决定） |
| 长任务（写文章、代码生成） | 不设置（让模型自己决定） |
| 节省成本 | 设置较小值（如 4096） |
| 控制输出长度 | 设置固定值 |

## 自定义配置

在 `~/.vermes/config.yaml` 的 `model` 部分添加 `max_tokens`：

```yaml
model:
  provider: xiaomi
  default: mimo-v2.5-pro
  max_tokens: 8192  # 可选，不设置则让模型自己决定
```

## 建议

- **大多数用户**：不设置 max_tokens，让模型自己决定
- **需要控制成本**：设置较小值（如 4096）
- **需要长输出**：不设置，让模型自己决定

## 验证配置

配置后重启 Vermes，查看日志中的 `[Stream]` 行，会显示实际使用的 max_tokens 值。
