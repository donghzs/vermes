# Vermes 2.1.1 — 直连大模型创作空间来了

为什么你还需要打开三个网页、切换两个工具，才能完成"让 AI 写文案"和"让 AI 生成配图"这两件事？

Vermes 2.1.1 把这两件事放在了一个应用里。不需要切换，不需要复制粘贴。

---

## 两种模式，一个窗口

打开 Vermes，左侧有两个入口：

| | 🧠 Agent 模式 | 🎨 Studio 模式 |
|---|---|---|
| **定位** | AI 对话助手 | 直连大模型创作台 |
| **能做什么** | 问答、搜索、写代码、分析文件 | 文生图、图生图、文生视频 |
| **怎么用** | 聊天框直接说 | 选模型 → 输入指令 → 出图 |
| **记忆** | 持久化，关应用不丢 | 临时创作台，关窗口即清 |
| **输出方式** | 文字回复，文件报路径 | 图片视频直接展示在聊天框 |
| **适合场景** | 长期项目、深度研究 | 快速出图、灵感探索 |

互不干扰。Agent 在后台持续思考，Studio 在前台快速出图。

---

## Studio 能做什么

### 📝 文本对话
对接任意 OpenAI 兼容接口。Agnes、DeepSeek、通义千问……填 Base URL 和 Key 即用。

### 🖼️ 图片生成
- **文生图**：输入「一只柴犬在咖啡馆喝咖啡」→ 秒出
- **图生图**：拖一张照片进来，输入「换成赛博朋克风格」→ 出图
- **人物一致性**：描述角色面部特征 + 新场景，模型稳稳保持长相

图片几乎秒出。

### 🎬 视频生成
- **文生视频**：输入「小猫在草地奔跑 3 秒」→ 提交 → 等待生成
- **图生视频**：上传图片 + 输入 → 提交

> 视频生成需要排队，请耐心等待。这是当前 AI 视频模型的普遍现状，不是我们的问题。

### ✨ 交互细节
- 支持拖拽上传图片
- 多任务并行：发了视频可以继续生成图片，互不阻塞
- 视频生成完成后自动变成播放器
- 配置自动保存，下次打开不用重填

### 🔌 支持的供应商

预设了 Agnes AI、DeepSeek、小米 MiMo、OpenAI、阿里通义。也支持自定义 Base URL + 模型名，想接谁接谁。

## Agent 模式一如既往

Agent 对话能力完全不受影响。搜索、写代码、读文件、调用工具……你在 Vermes 里跟 Agent 的所有互动都还在。

Agent 和 Studio 共用同一个应用，但代码、存储、生命周期完全隔离。不是一个改了另一个就崩。

## 已知限制

- **产品换背景**（遥控器、商品图）：Agnes 直连无法精确保持产品主体。这个是模型能力边界，后续走 ComfyUI 方案。
- **视频时长**：AI 视频普遍 2-5 秒。短剧创作需要独立工作流引擎。
- **角色一致性**：人物面部 100% 保持，但不是所有模型都行。用 Agnes Image 2.1 Flash 效果最好。
